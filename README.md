# NEXUS - Realise Your Digital Potential

NEXUS is a high-performance, modern marketing agency landing page designed to help brands scale their digital presence. Built with **React**, **Vite**, and **Tailwind CSS**, it features smooth animations and a premium aesthetic.

## 🚀 Features

- **Responsive Design**: Optimized for mobile, tablet, and desktop.
- **Micro-Animations**: Interactive UI elements using **Framer Motion**.
- **Dual Email Notification**: Integrated with **EmailJS** to send automated notifications to both the Admin and the User upon form submission.
- **Modern UI/UX**: Clean, minimal design with a focus on conversions.

## 🛠️ Tech Stack

- **Frontend**: React 19
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide-React
- **Form Handling**: EmailJS Browser
- **Build Tool**: Vite

## ⚙️ Setup & Environment Variables

To get the contact form working, you need to set up an [EmailJS](https://www.emailjs.com/) account and create a `.env` file in the root directory.

### Environment Variables (.env)

```text
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_ADMIN_TEMPLATE_ID=your_admin_notification_id
VITE_EMAILJS_USER_TEMPLATE_ID=your_user_acknowledgment_id
VITE_EMAILJS_PUBLIC_KEY=your_public_key
```

### Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Locally**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```
